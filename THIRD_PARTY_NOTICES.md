# Уведомления о сторонних материалах

Этот файл перечисляет материалы, которые не входят в оригинальные материалы
автора и не покрываются лицензией репозитория. Названия лицензий здесь не
предполагаются: для каждого компонента действуют условия его поставщика или
правообладателя.

## Зависимости Python

Пакеты, объявленные в `pyproject.toml`:

- runtime: `httpx`, `selectolax`, `pydantic`, `pydantic-settings`,
  `psycopg[binary]`, `sqlalchemy`, `alembic`, `zstandard`, `numpy`, `boto3`;
- development: `pytest`, `ruff`;
- optional embeddings: `mlx`, `mlx-embeddings`;
- build: `hatchling`.

Транзитивные зависимости здесь не перечислены. Их собственные уведомления и
условия должны сохраняться в установленных дистрибутивах.

## Фикстуры публичных судебных порталов

Файлы `tests/fixtures/ksoyu_*.html`, `tests/fixtures/kad_search_fragment.html` и
`tests/fixtures/captcha_reference.json` содержат сохранённые ответы и эталонные
данные публичных страниц судебных порталов, используемые для тестов. Фикстура
КАД — фрагмент ответа `POST /Kad/SearchInstances` с картотеки арбитражных дел
(`kad.arbitr.ru`), снятый при сборе. Происхождение живых HTML-фикстур и дату их
съёма описывает `tests/conftest.py`; файлы также могут содержать ссылки на
внешние ресурсы.

Эти материалы не считаются оригинальным кодом автора и не лицензируются по
CC BY-NC-ND 4.0. Их права, условия доступа, уведомления и ограничения нужно
оценивать отдельно по соответствующему источнику; этот файл не заявляет
конкретную лицензию для них.

## Маскировка браузера КАД

Маскировка автоматизации в `src/harvester/kad.py` (флаги запуска Chromium,
подавление трекеров, скрипт `_STEALTH` с подменой `navigator.webdriver` и
разведочного WebSocket, последовательность «мышь → пауза → клик»,
экспоненциальное ожидание cookie) выполнена по мотивам сервиса
`cookie-fetcher` проекта [court-case-monitor](https://github.com/zeotq/court-case-monitor)
(zeotq), лицензия [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).

лицензии распространяются на заимствованные решения в той мере, в какой они
сохраняют узнаваемую форму. CC BY-NC-ND 4.0 репозитория на сторонний код
не распространяется.
