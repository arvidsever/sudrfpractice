# Декретум как внешний источник

19.08.2026 обнаружился доступ к API корпуса «Декретум». Ниже — что он даёт,
чего не даёт и почему харвестер остаётся нужным.

## Объём

| | |
| --- | --- |
| Федеральные суды | 127 893 886 дел |
| из них кассация | **3 620 442** |
| Мировые судьи | 114 653 356 |
| Свежесть | 2026 год — 4,8 млн записей |
| Наш доступ | партнёрский: 5 000 запросов в сутки, 100 000 в месяц, 600 текстов в час |

## Данные богаче наших

По кассационному делу Декретум отдаёт то, чего в строке перечня нет:

| Поле | Харвестер | Декретум |
| --- | --- | --- |
| Номер, даты, судья, результат | да | да |
| Стороны | одной строкой из третьей колонки | списком, с ролями |
| Статьи | нет | разобраны: «УК РФ: ст. 228.1 ч.4 п. а» |
| Регион первой инстанции | внутри колонки | отдельным полем |
| Текст акта | собираем сами | есть у части дел |

Разбор статей — это задача 6.2 плана, уже сделанная.

## Сверка: наш парсер читает выдачу верно

Взяты 19 дел 5 КСОЮ, поступивших 18.03.2026, из нашей базы, и та же дата
запрошена у Декретума. Восемнадцать из девятнадцати нашлись в первых
50 записях, и **все восемнадцать совпали полностью** — судья и дата
решения до дня.

Это независимая проверка разбора: сверка со счётчиком суда ловит потерю
строк, но не ловит перепутанные колонки. Здесь колонки подтверждены чужими
данными.

Попутно: у Декретума за тот день 80 дел, у нас 19. Расхождение ожидаемое —
мы собирали окно по дате ПУБЛИКАЦИИ, а не поступления, и это лишний
довод в пользу второй оси.

## Чего API не заменяет

**Массовую выгрузку.** Наш корпус — 2,6 млн дел, лимит — 100 000 запросов
в месяц. Выкачать корпус через API значит потратить больше двух лет.
Он построен для поиска и точечных обращений.

**Тексты целиком.** Замер по 5 КСОЮ, гражданская кассация:

| Год | Дел | С текстом | Доля |
| ---: | ---: | ---: | ---: |
| 2019 | 1 008 | 308 | 31 % |
| 2020 | 3 934 | 1 647 | 42 % |
| 2021 | 4 523 | 2 810 | 62 % |
| 2022 | 16 296 | 4 999 | 31 % |
| 2023 | 12 224 | 10 487 | 86 % |
| 2024 | 12 476 | 7 948 | 64 % |
| 2025 | 9 775 | 8 151 | 83 % |
| 2026 | 5 551 | 2 340 | 42 % |
| **итого** | **65 787** | **38 690** | **59 %** |

Способ замера: полнотекстовый `q` ищет только по текстам, поэтому счётчик
с `q` и без него даёт покрытие. Проверено двумя разными словами —
«установила» дало 38 346, «суд» 38 705, то есть меряется именно наличие
текста, а не частота слова.

У 2 КСОЮ за 2026 год текстов не нашлось вовсе, у 5 КСОЮ за январь 2026 —
почти у всех. Покрытие сильно зависит от суда и года.

## Как это использовать

* **проверять** свой сбор независимым источником — сделано выше;
* **обогащать** собранное сторонами и статьями, которых в перечне нет;
* **закрывать дыры**, где суд нас не пускает;
* **отвечать на вопросы уже сегодня**, пока корпус собирается.

## Чем это не является

Чужой сервис: корпус не наш, условия использования нам не известны, квоты
чужие. Строить проект в зависимости от него — другая архитектура, чем
владеть корпусом. Плюс метаданные содержат полные ФИО сторон — та же
история с персональными данными, что в `docs/ethics.md`, только объёмом
больше.
