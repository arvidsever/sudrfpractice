# КС РФ: разведка 04.10.2026

## Главное: с сервера сайт недоступен

`ksrf.ru`, `www.ksrf.ru` и `doc.ksrf.ru` живут на одном адресе
`95.173.151.218`. С сервера TCP не открывается ни на 443, ни на 80 —
со всех трёх его адресов (`157.22.184.130`, `157.22.184.173`,
`157.22.194.96`): пакеты молча отбрасываются. С мака соединение проходит.
То есть сайт фильтрует адреса провайдера или их геолокацию — как ГАС
в августе (`network-access.md`), но сам по себе: ГАС с тех пор нас пускает.

Вторая особенность: сертификат выдан на корне Минцифры («Russian Trusted
Root CA», SHA-256 `D26D2D02…CA8ECF31`), которого нет в стандартных
хранилищах. Для проверки с мака корень взят из связки ключей мака;
для сервера его придётся положить рядом с кодом и подключать только для КС.

Разведка поэтому шла с мака: восемь запросов через тот же клиент.

## Устройство сайта

* «Битрикс», UTF-8. Список решений — `/Decision/`, по 10 на страницу,
  **6 008 страниц — около 60 тысяч решений**. Виды: постановления,
  определения, решения, заключения, представления.
* Каждое решение — PDF `/doc/KSRFDecision{номер}.pdf`, **с текстовым
  слоем**: определение на 6,8 тыс. знаков вынимается целиком той же
  функцией, что акты ВС.
* Листание — параметр `PAGEN_1`, и `robots.txt` его запрещает
  (`Disallow: /*PAGEN`). Карта сайта решений не содержит — там новости,
  пресс-релизы и заседания, и обновлялась она в июне 2025. Других путей
  перечислить решения не видно; по решению владельца (`ethics.md`)
  `robots.txt` проект не соблюдает, но здесь это стоит помнить отдельно.
* Поиск с периодом (`start`, `end`) и видом (`decType…`): за сентябрь 2026
  выдал 4 строки — похоже, по умолчанию отбирает не все виды; уточнять
  при разработке.

## Цена

~6 тыс. страниц списка и ~60 тыс. PDF — около 66 тыс. запросов,
двое-трое суток при 3 с на запрос. Новых решений — порядка полутора
десятков в рабочий день.
