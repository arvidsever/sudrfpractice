# MCP-сервер поиска

Зачем: скилл `sudrf-practice` ходит на сервер по `ssh` с ключом владельца
и работает только в Claude Code на его маке. В Cowork, в вебе и на телефоне
ключа нет. MCP-сервер отдаёт те же две команды — `search` и `act` — как
инструменты коннектора.

## Состояние на 06.10.2026

**Работает локальный режим на маке владельца.** Коннектор `sudrf-practice`
прописан в `claude_desktop_config.json` приложения Claude: stdio-сервер,
который ходит в корпус по `ssh` (`SUDRF_MCP_SSH=root@157.22.194.96`).
Наружу ничего не открыто.

```json
"sudrf-practice": {
  "command": "<репозиторий>/.venv/bin/python",
  "args": ["-m", "harvester.mcp_server"],
  "env": {"PYTHONPATH": "<репозиторий>/src", "SUDRF_MCP_SSH": "root@157.22.194.96"}
}
```

**HTTP-режим на сервере не включён.** Код и задание systemd лежат
в репозитории; на сервере ничего не установлено и порт не открыт.
Публикация сервиса в интернет — отдельное решение владельца: она открывает
на машине, которую и так непрерывно подбирают по SSH, ещё одну дверь
к корпусу с необезличенными ФИО. Нужна только для веба и телефона.

## Как устроено

`src/harvester/mcp_server.py`, протокол — Streamable HTTP, без сессий.

* **Инструменты вызывают CLI** и возвращают его вывод: формат выдачи один
  и уже выверен под чтение моделью.
* **Только чтение.** Задание запускается с
  `default_transaction_read_only=on` и `statement_timeout=30000`.
* **Доступ — секрет в пути адреса** (`/<секрет>/mcp`), не короче 32 знаков.
  Коннектор claude.ai умеет OAuth либо ничего, а пользователь один.
  Журнал запросов выключен, чтобы секрет не попадал в journald.
* **Слушает `127.0.0.1:8765`.** TLS и внешний адрес — дело обратного прокси.

## Что нужно, чтобы включить HTTP-режим

1. `pip install '.[api]'` в окружение сервера.
2. `/etc/sudrf/mcp.env` (600, root): `SUDRF_MCP_SECRET=…`,
   `SUDRF_MCP_HOST=<имя хоста>`.
3. `deploy/systemd/sudrf-mcp.service` → `systemctl enable --now sudrf-mcp`.
4. Обратный прокси с TLS на внешнем адресе и открытый порт 443. Своего
   домена у сервера нет (`arvidsever.fvds.ru` указывает на другой адрес);
   годится имя вида `157-22-194-96.sslip.io`. Слушать нужно именно внешний
   адрес: `127.0.0.1:443` занят туннелем КС.
5. В claude.ai — пользовательский коннектор с адресом
   `https://<имя хоста>/<секрет>/mcp`.
