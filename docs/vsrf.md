# ВС РФ: разведка 03.10.2026

Шесть заходов, около 25 запросов, под своим замком платформы ВС — параллельно
со сбором ГАС (см. `ethics.md`, замок и дроссель по платформе).

## Устройство сайта

* `robots.txt`: `Allow: /`, `Disallow: /api/`. Разделы `/lk/practice/acts`
  и `/lk/practice/claims` открыты — в отличие от ГАС, здесь правила сайта
  сбору не мешают.
* Страницы — Next.js, но **с серверной отрисовкой**: данные лежат прямо
  в странице, в `<script id="__NEXT_DATA__">`, поле
  `props.pageProps.initialItemsData` — `{content: HTML строк, totalElements,
  last}`. Скрытый `/api/` не нужен.
* **Листание** — параметр `page` в адресе, с нуля, по 20 строк. Скрипт
  страницы делает ровно это: `Math.max(0, Number(query.page) || 0)`.
* Капчи нет, ответы в UTF-8.

## Два входа

**Тексты актов** — `/lk/practice/acts`. Фильтры: `actDateFrom`/`actDateTo`
(дд.мм.гггг), `caseType`, `instance`, `actTypeId`, `judgeName`, `keywords`,
`number`. Строка выдачи: номер, вид акта, дата, вид судопроизводства,
инстанция, предмет, коллегия, судья-докладчик, ссылка на PDF
(`/lk/practice/stor_pdf/{id}`) и **ссылка на карточку производства**.

**Карточки производств** — `/lk/practice/claims`. Фильтры: даты поступления
и рассмотрения «от–до», `caseType`, `instance`, `claimType` (`CASE` — дело,
`APPEAL` — жалоба). Строка выдачи уже содержит всё для связи с нашим
корпусом: номер, дату поступления, вид, инстанцию, **УИД**, суд первой
инстанции с датой и судьёй, номер дела первой инстанции, результат,
предмет, участников.

## PDF

Сканы с распознанным текстовым слоем поверх: по картинке на страницу
и один-два шрифта. Текст вынимается целиком (PDFKit, три акта по 6–12
страниц, 15–32 тыс. знаков), качество для поиска достаточное, мелкие
огрехи вида «Дело№АПЛ26-201». Распознавать заново не нужно. Размер —
0,4–0,8 МБ на акт.

## Цена

* **Акты без экономических**: ~13 тыс. страниц выдачи и ~254 тыс. PDF.
  При 3 с на хост — около 9–10 суток, параллельно с ГАС. PDF — порядка
  130 ГБ: только в S3, локально не держать. Текст в базе — порядка 5 ГБ,
  с полнотекстовым индексом — около 12.
* **«Дела» из выдачи карточек**: ~15 тыс. страниц, полсуток. Отдельные
  карточки для связи не нужны — всё есть в строке выдачи.
* **Жалобы** — миллионы строк без УИД и без опубликованных актов; брать
  не стоит.
